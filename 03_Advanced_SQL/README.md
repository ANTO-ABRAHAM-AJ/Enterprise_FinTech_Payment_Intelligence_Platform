# Advanced SQL

## Overview

This folder demonstrates advanced SQL Server programming concepts used in enterprise analytics applications.

## Topics Covered

- SQL Views
- Stored Procedures
- User Defined Functions
- Window Functions
- Common Table Expressions (CTEs)
- CASE Expressions
- EXISTS / NOT EXISTS
- UNION ALL
- CROSS APPLY
- Running Totals
- Moving Averages
- Ranking Functions

## Files

01_Views.sql

Reusable reporting views.

02_Stored_Procedures.sql

Parameterized procedures for business reporting.

03_User_Defined_Functions.sql

Scalar and table-valued functions.

04_Advanced_SQL_Demo.sql

Comprehensive demonstrations of advanced SQL Server techniques.
