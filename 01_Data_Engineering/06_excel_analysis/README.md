# Excel Business Analysis

## Overview

This folder contains exploratory business analysis performed in Microsoft Excel before the data was modeled in SQL Server.

## Objectives

• Understand transaction behavior

• Validate business assumptions

• Analyze fraud distribution

• Study transaction amounts

• Analyze temporal trends

• Examine balance movement

• Produce executive summaries

## Files

01_data_exploration.xlsx

Initial exploration and data understanding.

02_data_validation.xlsx

Warehouse validation and integrity checks.

03_Business_Pivot_Analysis.xlsx

Business analysis using Pivot Tables, Pivot Charts, and Executive Dashboard.
