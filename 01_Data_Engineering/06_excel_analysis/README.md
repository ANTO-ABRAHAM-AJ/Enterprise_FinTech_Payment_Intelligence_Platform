## 📖 Overview

This folder contains exploratory business analysis performed using **Microsoft Excel** prior to data warehousing and advanced analytics.

The analyses provide an initial understanding of transaction behavior, fraud patterns, financial characteristics, and operational trends within the PaySim dataset. These insights guided the subsequent SQL data warehouse design, business analytics, machine learning workflows, and Power BI dashboard development.

---

## 🎯 Objectives

The Excel analysis was conducted to:

- Understand transaction behavior across different payment types.
- Validate dataset quality before data warehousing.
- Analyze fraud distribution and business risk patterns.
- Study transaction amount characteristics.
- Examine temporal transaction trends.
- Evaluate account balance movements.
- Generate executive-level business summaries.
