## 📖 Overview

This folder contains analytical SQL queries built on top of the Enterprise FinTech Payment Intelligence warehouse.

The queries answer business questions related to:
* Payment Performance
* Account Behavior
* Fraud Detection
* Money Flow
* Query Performance
* Business Case Studies

---

## 🛠️ Skills Demonstrated

- SQL Joins & Aggregations (`GROUP BY`, `CASE`)
- Advanced T-SQL (CTEs, Window Functions, Ranking Functions)
- Analytical Calculations (Running Totals, Moving Averages)
- Database Optimization (Query Optimization, Execution Plans, Performance Analysis)

---

## 📁 Files

| File | Description |
