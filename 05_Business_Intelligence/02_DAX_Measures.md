# DAX Measures

## Overview

This document describes the key DAX measures used throughout the Enterprise FinTech Payment Intelligence Platform.

---

## Executive KPIs

- Total Transactions
- Total Transaction Value
- Average Transaction Value
- Fraud Transactions
- Fraud Rate
- Global Fraud Rate
- High Value Transactions
- Total Source Accounts
- Total Destination Accounts

---

## Machine Learning KPIs

- ML Champion Model
- ML Precision
- ML Recall
- ML ROC AUC

---

## Business Purpose

These measures power KPI cards, trend analysis, fraud monitoring dashboards, and machine learning explainability pages.

The calculations are optimized to provide real-time business insights while maintaining a clean and reusable semantic model.
